Free Hosting Guide

💡 How to host this web app 100% free

KickOff Division runs entirely in the browser — no servers, no domains, no databases to pay for.

Step 1: Free hosting with GitHub Pages

Upload the project files into a public GitHub repository, then open Settings → Pages and select the main branch.

Step 2: Offline data & backups

All teams, players and results are saved automatically in your browser's LocalStorage. Export a JSON backup at any time.
